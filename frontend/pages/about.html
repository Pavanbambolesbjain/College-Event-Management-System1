About CampusConnect

An advanced-yet-accessible event automation portal built to revolutionize student engagement, event coordination, and rating moderation in academic environments.

Stateless Architecture

Utilizes modern JWT validation inside HTTP-only cookies, securing routes against cross-site script request issues while allowing pre-rendered page redirects from Express middleware.

JSON Database Core

Strictly adheres to the engineering evaluation rubric by simulating transactional behaviors through structured, fast, file-locked JSON datasets, eliminating SQL configuration complexity.

Interactive Analytics

Provides administrator panels to check active registrations, gauge event categories, track seat utilization, and monitor review averages calculated from live records.

Designed for Engineering Vivas

CampusConnect addresses the key challenges in college event registration: manual forms, unverified attendance records, double-booking, and lack of visual analytics dashboards.

Its simple structure makes it highly transparent, allowing students to explain code structures (routers, controllers, utils, file read-writes) easily during final-year engineering oral examinations.

Project Specifics
